# 学习路线模板（`1.<主题>学习路线.md`）

学习路线是整个学习资料的骨架，章节顺序以它为准。严格按下面的结构和符号约定生成。

## 整体结构

```
# <主题> 学习路线

## 这条路线是什么？        ← 可选但推荐
（2-3 句说明覆盖范围 + 学习顺序的编排逻辑）

### 适合谁？
- 受众 1
- 受众 2

---

## 学习路线

### 🟢 第一阶段：阶段名（预计 X 天）
### 🔵 第二阶段：...
...（多个阶段）

---

## 完整学习时间线        ← 必有，表格
## 练手建议              ← 必有，列出 3-5 个可做的小项目
```

## 阶段（Phase）格式

- 阶段标题：`### <彩色圆点> 第N阶段：阶段名（预计 X 天）`
- 圆点按难度由易到难循环使用：`🟢 → 🔵 → 🟡 → 🟠 → 🔴 → 🟣`（绿到紫，大致对应入门到进阶）。
- 阶段标题下紧跟一行加粗目标：`**目标：……**`
- 再跟一行 `💡` 引用块点题，说明这个阶段为什么重要 / 学完能干什么：
  ```
  > 💡 流程控制是编程的"骨架"。有了它，代码才能根据不同情况做不同的事。
  ```

## 知识点（Knowledge Point）格式

- 知识点**跨阶段连续编号**（第一阶段是 1-5，第二阶段接着 6-10，不要每阶段从 1 重来）。
- 格式：`N. **知识点名** ⭐⭐⭐ 🎯`
  - `⭐` 表示重要度/难度，1-3 颗：`⭐` 了解即可、`⭐⭐` 重要、`⭐⭐⭐` 必须熟练。
  - `🎯` 可选，标记「核心必掌握」的知识点。
- 知识点下用子弹点列出细节：核心语法 / 命令、代码示例（用反引号）、分类小标题（如 `**算术运算符**：`）。
- 几乎每个知识点结尾带一句通俗总结：
  ```
  - 「一句话总结」：函数 = 给一段代码起个名字，需要的时候喊一声就行
  ```
- 重要知识点再加一条提醒，二选一：
  - `- ⚠️ 踩坑：……`（常见错误 / 易混点）
  - `- ⚠️ 面试高频：……`（面试常考点）

## 时间线表格（结尾必有）

```markdown
## 完整学习时间线

| 阶段 | 内容 | 预计时间 | 难度 |
|------|------|----------|------|
| 🟢 第一阶段 | 环境与基础 | 2-3 天 | ⭐ |
| 🔵 第二阶段 | 数据类型与运算符 | 3-4 天 | ⭐ |
| ... | ... | ... | ... |
| **总计** | | **约 X 周** | |

> 💡 （一句节奏建议，强调动手实践，光看不练等于没学）
```

难度列这里可以用到 `⭐⭐⭐⭐`，比知识点的 3 星上限更高，用来体现阶段整体难度梯度。

## 练手建议（结尾必有）

```markdown
## 练手建议

- 项目 1（一句话描述，能综合用到本路线的知识）
- 项目 2
- ...
```

## 完整片段示例（照此风格写）

```markdown
### 🟠 第四阶段：函数（预计 4-5 天）

**目标：掌握函数的定义和使用，能写出结构清晰、可复用的代码。**

> 💡 函数是代码复用的基本单位。把重复的逻辑封装成函数，代码立刻变得清晰。

14. **函数定义与调用** ⭐⭐⭐ 🎯
    - `def` 定义函数
    - 参数类型：位置参数、默认参数、`*args`、`**kwargs`
    - `return` 返回值，支持多值返回
    - 「一句话总结」：函数 = 给一段代码起个名字，需要的时候喊一声就行
    - ⚠️ 踩坑：默认参数不要用可变对象（如 list、dict），否则多次调用会共享同一个对象

15. **作用域** ⭐⭐⭐
    - 局部变量 / 全局变量、`global` / `nonlocal`、LEGB 规则
    - 「一句话总结」：变量的"可见范围"就是作用域，搞不清楚就会出 bug
```

## 主题适配提示

- **编程语言**：阶段按「环境 → 语法基础 → 进阶特性 → 工程化」推进，知识点配代码片段。
- **数据库**：阶段按「概念架构 → 表设计 → 增删改查 → 索引/事务/锁 → 优化 → 运维」推进，知识点配 SQL 片段。
- **CLI 工具（如 Redis）**：阶段按「概念架构 → 核心命令/数据类型 → 进阶机制 → 持久化/集群 → 实战问题」推进，知识点配命令片段。
- **框架/库**：阶段按「环境与 Hello World → 核心概念 → 常用功能 → 进阶 → 部署/项目」推进。
- **纯理论**：阶段按「概念 → 分层/分类展开 → 综合 → 实际应用」推进，知识点配图示或伪代码。
